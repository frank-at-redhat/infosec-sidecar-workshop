= InfoSec Sidecar Workshop

This workshop is for platform and security engineers who run Red Hat OpenShift Service Mesh and need applications outside the mesh to call in with their own SPIFFE identity, verified end to end rather than at the edge.
By the end, you can build the whole path yourself: a SPIRE identity plane with Zero Trust Workload Identity Manager, a mesh that issues sidecar certificates from it, a Gateway API listener that passes TLS through on SNI, federation with a second trust domain, and the InfoSec sidecar that an external application runs to join in.
